# taojinshu-ai-conversation 测试规范

## 1. 测试目录

测试与源码同目录：Projector、Composer、Viewport、Controller 各自保存 `*.spec.ts`；
跨这些子模块的测试保存为 `src/taojinshu-ai-conversation/conversation-controller.integration.spec.ts`。
具体路径以 [测试工程修订](../implementation/TEST-FOUNDATION.md) 为准。

## 2. 必测行为

- replay 前后 Timeline 相同。
- IME composition 不误发送。
- 发送失败保留草稿和 Resource 引用。
- following/detached 切换、未读累计和 showLatest。
- 历史前插保持 anchor。
- 高频 100 次 Runtime 更新不会产生 100 次 Web 重排承诺。
- dispose 后停止通知但不销毁共享 Runtime。

## 3. 测试边界

Conversation 测试使用 Fake Runtime、Fake DraftRepository、Fake ViewportPort 和 Fake Scheduler，不使用 jsdom 测量、不启动真实后端。DOM、键盘和视觉属于 UI 测试。

```bash
pnpm exec vitest run src/taojinshu-ai-conversation
pnpm check:ai-boundaries
pnpm exec vue-tsc --noEmit
```
