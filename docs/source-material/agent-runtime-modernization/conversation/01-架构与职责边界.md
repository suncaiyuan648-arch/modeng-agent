# taojinshu-ai-conversation 架构与职责边界

## 1. 输入和输出

```text
AgentRuntime ReadonlyRuntimeState
  -> ConversationProjector
  -> ConversationViewModel / Timeline
  -> ComposerController / ViewportController
  -> taojinshu-ai-ui
```

## 2. 负责范围

- Session 级 Timeline 投影和稳定排序。
- Message 展开、已读、选择和动画等可丢弃状态。
- Composer 草稿、IME、Resource 引用、提交和停止控制。
- Viewport following/detached/restoring/loading-history 状态机。
- 流式 UI 通知批量调度。
- Draft、Viewport、Clipboard 等交互端口。

## 3. 禁止范围

- SSE、WebSocket、chunk decoder 和 raw Event。
- Operation/Event Reducer、状态机和 RuntimeState 写入。
- Agent Snapshot、EventRepository 和服务端 replay。
- Vue、Pinia、Router、Element Plus、HTMLElement 和全局 `uni`。
- Geo/PPT 等业务规则和具体 Renderer。

## 4. Session 语义

v1 以 SDK `SessionId` 作为 ConversationViewModel key，不建立第二个持久化 ConversationId。当前后端 `sessionId` 直接由 Legacy Adapter 映射。只有出现一条前端会话聚合多个服务端 Session 的真实需求后，才新增映射实体。

## 5. Message 所有权

SDK 保存 AgentMessage、MessageContentBlock、ToolCall、Artifact 和 Resource 的事实。Conversation
只保存引用以及本地交互状态。ToolCall/Artifact/Resource 不复制到 Message；Projector 在同一
RuntimeState 快照内联结。

## 6. 生命周期

ConversationController 由 `ai-application` 创建。它订阅 Runtime，session 切换时恢复草稿和 Viewport，本地 dispose 时取消订阅和调度；它不能 dispose 共享 AgentRuntime。
