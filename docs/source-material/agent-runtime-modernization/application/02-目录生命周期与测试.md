## 2. Geo 页面门面

```ts
export interface GeoResearchFacade {
  /** 当前 Runtime 快照投影出的只读研究视图。 */
  readonly researchView: Readonly<GeoResearchViewModel>;
  /** 校验输入并请求创建新的 Geo 研究 Operation。 */
  startResearch(input: GeoResearchInput): Promise<CommandReceipt>;
  /** 请求取消当前非终态研究 Operation。 */
  cancelResearch(): Promise<CommandReceipt>;
  /** 请求针对指定平台创建重试 Operation。 */
  retryPlatform(platformId: string): Promise<CommandReceipt>;
}
```

门面可依赖 Geo 的公共 Definition/ViewModel，但 Geo 模块不得反向依赖 Application。Pinia 只保存
命令提交态和只读投影引用，不复制 Operation、Artifact 或 sequence。

## 3. owner 切换顺序

```text
停止新 Command
  -> 关闭实时订阅
  -> flush Event/Snapshot
  -> dispose Conversation
  -> 清理内存状态
  -> 清理旧 owner 本地 Namespace
  -> 创建新 owner Application context
```

## 4. 测试

测试 main.ts 只注册一个 Manager、同 Workspace context 复用、同 Session Controller 复用、Runtime
恢复完成前不返回 Conversation、未知 Agent 拒绝、稳定 owner、token 刷新不换 Namespace、owner 清理、
草稿隔离、Adapter 冻结、Flag 回滚、Legacy Port 注入、Resource 短时地址、Intent 权限和 dispose 幂等。
Application 测试可以使用 Fake Platform，不要求真实 Router/后端。
