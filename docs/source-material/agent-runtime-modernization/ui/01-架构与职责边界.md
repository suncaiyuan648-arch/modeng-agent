# taojinshu-ai-ui 架构与职责边界

## 1. 负责范围

- ChatViewport、MessageList、MessageBubble 和 MessageBlockRenderer。
- AiComposer、附件展示、语音/模型/Agent/Tool 选择 slot。
- ArtifactCard 通用外壳和 Unsupported fallback。
- Web DOM/visualViewport/键盘/可访问性。
- uni scroll-view、App/小程序键盘和安全区。
- Theme Token、组件样式和平台视觉一致性。

## 2. 输入

UI 只接收：

- ConversationViewModel、ComposerController、ViewportController。
- SDK MessageContentBlock/Artifact 的只读 ViewModel 和 UiIntent。
- Application 提供的 ResourcePicker、ModelSelector、AgentSelector 和 IntentExecutor。

## 3. 禁止范围

- 直接调用 Chat/Geo API 或解析 SSE。
- 修改 RuntimeState、Operation、Message 和 Artifact。
- 将页面组件导入通用 UI。
- 根据后端 component/componentPath 动态加载代码。
- 使用 `content:any` 或未经 Schema 校验的 props。

## 4. 组件原则

通用组件为受控组件：状态来自 Controller/ViewModel，用户行为向外发 Intent。Web 和 uni 共享语义契约和 Fixture，但不强求共享模板、DOM API 和样式实现。

## 5. Artifact 组合

```text
AiArtifactCard                       / 通用标题、状态、错误和动作区
  └── Agent Renderer                 / Geo/PPT 等业务内容
```

业务 Renderer 位于 `ai-agents/<agent>/renderer/<platform>`，由本地 Registry 注册；通用 UI 不依赖具体 Agent。
