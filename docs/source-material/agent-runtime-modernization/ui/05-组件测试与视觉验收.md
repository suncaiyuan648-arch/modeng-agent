# taojinshu-ai-ui 组件测试与视觉验收

## 1. Web 自动化

```text
src/taojinshu-ai-ui/web/chat/AiChatViewport.spec.ts
src/taojinshu-ai-ui/web/message/AiMessageBlockRenderer.spec.ts
src/taojinshu-ai-ui/web/composer/AiComposer.spec.ts
src/taojinshu-ai-ui/contracts/component-renderer-registry.spec.ts
src/ai-agents/geo-ad/renderer/web/GeoResearchReportRenderer.spec.ts
```

必须覆盖 following/detached、历史 anchor、IME、停止、未知 Block、Artifact fallback、危险 Intent、PC/mobile props 语义和可访问名称。

## 2. Uni 自动化

Web 与 uni 使用同一 semantic Fixture，断言 Timeline 顺序、角色、streaming、Artifact status、Intent type 和 Composer disabled 一致。平台测试额外覆盖 chunk/polling 状态、后台恢复和存储降级提示。

## 3. 手工验收

- PC Chrome/Safari：长消息、代码块、Artifact、历史加载。
- iOS Safari/WebView：键盘、安全区、弹性滚动、语音用户手势。
- Android Chrome/WebView：键盘 resize、返回键、文件选择。
- 微信开发者工具和真机：scroll-view、轮询、存储配额。

## 4. 责任边界

Timeline/Viewport 决策错误归 QA-WP2；DOM/键盘/样式错误归 QA-WP3；Schema/Intent/Artifact 错误归 QA-WP4；uni 平台错误归 QA-WP6。
