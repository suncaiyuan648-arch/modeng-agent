# Geo Ad Agent 目录与接口规范

```text
src/ai-agents/geo-ad/                         / Geo Agent 业务插件根目录
├── index.ts                                  # 稳定导出
├── domain/                                   / Campaign、ResearchReport 等业务模型
├── contracts/                                / 当前后端 Legacy DTO
├── adapter/                                  / Mock、Legacy 和 v1 Transport Adapter
├── definition/                               / AgentDefinition、phase 和 Projector
├── schema/                                   / Geo Input/Artifact Schema 与迁移
├── renderer/web/                             / Geo Web 业务 Renderer
├── renderer/uni/                             / Geo uni 业务 Renderer
└── testing/                                  / Geo Fixture 和 conformance
```

## 公开接口

```ts
export interface GeoAgentDefinition extends AgentDefinition {
  /** Geo Agent 的稳定类型，用于与服务端 Descriptor 求交。 */
  readonly agentType: 'geo-ad';
  /** 将同一 Runtime 快照投影为 Geo 研究业务视图。 */
  readonly projectResearch: RuntimeProjector<GeoResearchViewModel>;
}
```

页面不得导入 Geo Event payload、Adapter 或本模块私有 Projector。页面使用的 `GeoResearchFacade` 归
[ai-application](../../application/README.md) 所有，避免业务插件同时承担装配和 Vue 桥接。Geo Renderer
只能通过 RendererDefinition 注册，通用 UI 不反向依赖 Geo。

## 测试

Geo Mock、Legacy 和 v1 Adapter 共用 normal/platform-failure/partial-success Fixture；cancel Fixture 只用于
声明 `serverCancel=true` 的 Mock/v1。Legacy 必须通过不可取消、不可重放、刷新后 interrupted 的能力差异 Fixture。
Projector 和页面测试只读取 GeoResearchViewModel。
