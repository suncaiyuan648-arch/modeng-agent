# taojinshu-ai-sdk 测试与发布规范

## 1. 测试分层

- Unit：Codec、Reducer、状态机、Projector、Schema。
- Conformance：Transport、Persistence、Agent Adapter。
- Integration：Command -> Event -> Runtime -> ViewModel。
- Recovery：Snapshot、delta、replay、owner 切换。
- Compatibility：协议 major、未知 critical Event、Artifact Schema。

## 2. 测试所有权

SDK 测试与被测源码同目录；跨多个 Core 子目录的黑盒集成测试放在
`src/taojinshu-ai-sdk/core/*.integration.spec.ts`。测试只使用公共入口和 `testing` Fixture，
不深层导入 internal handler。具体收集和 TypeScript 配置以
[测试工程修订](../implementation/TEST-FOUNDATION.md) 为准。

## 3. 注释和依赖门禁

```bash
pnpm check:ai-sdk-docs
pnpm check:ai-boundaries
pnpm exec vue-tsc --noEmit
pnpm exec vitest run src/taojinshu-ai-sdk
```

所有 SDK 文件、导出声明、字段、构造函数和方法必须有完整中文 TSDoc。禁止 SDK 导入 Vue、Pinia、Router、Element Plus、pages 和具体 Agent。

## 4. 发布入口

```text
@taojinshu/ai-sdk                       / Core、Domain、Protocol、Runtime
@taojinshu/ai-sdk/platform-web          / Web Adapter
@taojinshu/ai-sdk/platform-uni          / uni Adapter
@taojinshu/ai-sdk/testing               / Fixture 与 conformance
```

首期仍位于当前仓库源码目录。只有 Geo、PPT 两个领域和至少一个 uni 目标通过 conformance 后才允许独立发包。
