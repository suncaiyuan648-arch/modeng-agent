# taojinshu-ai-sdk 架构与职责边界

## 1. 负责范围

```text
External Command/Event
  -> Codec
  -> Event Processor
  -> Reducer + State Machine
  -> RuntimeState
  -> Projector
  -> Readonly ViewModel
```

SDK 负责 Agent 执行事实、协议兼容、顺序、幂等、领域状态、持久化恢复和平台端口。

## 2. 不负责范围

- Conversation Timeline、草稿、IME、滚动锚点和未读数。
- Vue/uni 视觉组件、主题和页面布局。
- Geo、PPT、数字人等业务 Domain 和 Renderer。
- 用户登录、Router、Feature Flag 装配和应用生命周期编排。

以上能力分别归属 `taojinshu-ai-conversation`、`taojinshu-ai-ui`、`ai-agents` 和 `ai-application`。

## 3. 内部依赖方向

```text
contracts/domain <- protocol <- reducer/state-machine <- runtime/recovery
ports             <- platform adapters
schema contract   <- renderer registry contract
```

Core 不依赖 platform implementation。所有副作用通过 Transport、Persistence、Clock、IdGenerator 和 Logger 端口注入。

## 4. 稳定性等级

| API | 稳定级别 | 变更规则 |
| --- | --- | --- |
| Command/Event Envelope | Stable v1 | 破坏性变化升 major |
| Domain IDs/状态枚举 | Stable v1 | 不复用旧语义 |
| AgentRuntime 门面 | Stable v1 | 只允许新增可选能力 |
| Internal Reducer handler | Internal | 不从根入口导出 |
| Platform Adapter 实现 | Adapter | 保持 conformance 即可替换 |

## 5. 不变量

- Event 是服务端事实，Reducer 是 RuntimeState 唯一写入口。
- 页面、Conversation 和 UI 只能读取投影，不能修改 Domain State。
- User Command 表示请求，只有 Event 能确认终态。
- `sequence` 在单 Operation 内连续；冲突和空洞不能静默跳过。
- SDK 公开对象为只读，外部 `unknown` 必须经 Codec。
